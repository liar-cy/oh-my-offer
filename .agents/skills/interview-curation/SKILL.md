# 面经整理工作流

开始使用时简短告知用户。先读根目录 `AGENTS.md`，以其为统一规则；本技能只描述执行步骤。若当前会话未自动发现技能，可直接读取本文件。

## 1. 识别材料与既有记录

读取 README 和相关面经，识别元信息，区分原始问题、候选人回答与反问反馈。根据来源及内容判断新增记录、已有记录补充或后续轮次。

分别分配全库 MJ 编号和目标“公司/轮次”目录内的数字文件名，两者互不推导。保留未知与歧义，不推测匿名身份或面试年份。

## 2. 组织面经问答

按原顺序将同一话题及追问整理成问答组，以 Q01、Q02 等连续整数编号。检查全部考点，避免机械拆细或跨话题过度合并。

使用 [面经模板](assets/interview-template.md) 生成口述答案，移除重复句子。个人事实不足时提供框架，模糊题意注明前提；面经文件不补充虚构的面试追问。

## 3. 匹配和维护专题

使用关键词、同义表述和考察意图检索已有题目，阅读候选正文后判断：新增独立题、补充既有答案，或仅追加问法与来源。

新增专题按 [专题模板](assets/topic-template.md) 连续编排问题；每题具备面试回答、技术细节、带答案的深挖追问。按需查证技术结论，保留适用版本与一手来源。

一组面经可关联多道专题题。添加双向标题链接，准确区分实际追问与补充练习。合并或重编号时更新目标、显示题号并去重来源；技术修订需检查对应面经答案。

## 4. 检查与交付

核对考点覆盖、编号、答案结构与所有受影响的文件／标题链接，更新 README 索引及统计。检查范围和统计口径遵循 AGENTS.md。

向用户说明实际输出、问答组数、专题新增／补充／仅追加来源数量，以及需要补充的信息。不另建每批处理报告；规则维护不生成虚构面经。
