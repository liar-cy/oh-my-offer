## Q04：Skill、MCP 和提示词的区别和作用是什么？

### 面试回答

提示词是给模型的指令和上下文；Skill 是可复用的任务方法包，包含指引并可附脚本、资料；MCP 是连接 AI 应用与外部工具和数据的协议。比如整理面经时，提示词说明本次需求，Skill 定义归档和去重流程，MCP 可用于读取外部资料。Skill 不等于工具服务，MCP 也不负责替模型决定业务流程。

## Q07：Spring Boot 自动装配的原理是什么？

### 面试回答

`@SpringBootApplication` 中的 `@EnableAutoConfiguration` 会导入自动配置候选类。Spring Boot 3 主要从 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 读取候选项，再通过 `@ConditionalOnClass`、`@ConditionalOnMissingBean`、`@ConditionalOnProperty` 等条件决定哪些配置生效。生效的自动配置本质上仍是向 IoC 容器注册 Bean；开发者自己定义了同类 Bean 时，很多默认配置会自动退让。

## Q08：IoC 和 AOP 是什么，具体原理是什么？

### 面试回答

IoC 把对象创建和依赖管理交给容器，Spring 读取配置形成 BeanDefinition，再实例化、注入、初始化，并通过后处理器等扩展生命周期。AOP 将事务、日志等逻辑集中处理，Spring AOP 通常通过 JDK 接口代理或 CGLIB 子类代理，在方法调用前后执行拦截器链。容器可以在 Bean 创建过程中返回代理；只有调用经过代理才会应用相应增强，同类 this 自调用通常绕过代理。具体代理类型及可拦截方法范围要结合配置和版本。

## Q10：表有姓名、科目、分数字段，查询分数都大于 80 分的人员名单。

### 面试回答

我会按人员分组，在 HAVING 中判断最小成绩大于 80。下面把 NULL 视为不合格，并暂按姓名区分人员：

```sql
SELECT name
FROM scores
GROUP BY name
HAVING MIN(score) > 80
   AND COUNT(score) = COUNT(*);
```

不能先 WHERE score > 80，否则低分会被提前过滤。真实表应按人员 ID 分组；如果要求所有应修科目都已参加考试，还需科目清单核对缺考。
