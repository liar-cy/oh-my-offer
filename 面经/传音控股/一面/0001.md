## Q02：canal 和 Kafka 怎么结合使用的，解决了什么问题？

### 面试回答

常见架构：canal server 伪装 replica 解析 binlog → 投递 Kafka topic → 各下游（缓存失效、ES 同步、数仓、审计）以独立 consumer group 消费。解决的问题：① 解耦与一对多广播——变更采集端不认识任何具体下游，加消费方不改 canal；② 削峰与重放——突发大批量变更先进 Kafka 缓冲，消费方按自己节奏拉取，位点可重置重放历史；③ 隔离故障——下游挂掉不影响采集，恢复后继续消费。顺序性约束：同一行/同一 key 要落同一分区保序，跨分区不保证全局序；Kafka 层还引入“至少一次”重复消费问题，消费端要幂等。项目实际拓扑按【真实配置】说。

## Q03：500ms 同步延迟怎么测试的？

### 面试回答

口径先说清“从哪到哪”：端到端延迟＝数据在主库提交到目标存储（缓存/ES）可查的时间差。测法两种：① 事件内带时间戳——canal 事件里取 binlog 提交时间（或自定义注入标记字段），消费落库后算 now−事件时间，按窗口聚合出 P50/P99；② 探针法——定时向源表写一条带标记的探测行，轮询目标端查到它计时，测的是完整链路。要避开的坑：把监控采集/心跳间隔当成端到端延迟、只报平均值不报分位数、压测环境和生产的批量参数不一致导致数字不可比。

## Q04：了不了解 harness？Agent 编排呢？

### 面试回答

harness 指模型外面那层“运行外壳”：上下文组装（指令、历史、检索结果、工具定义的编排与预算控制）、工具执行与结果回灌、循环控制与停止条件、状态持久化与恢复——同一个模型配不同 harness 能力差别很大，Claude Code、Codex 这类产品的差异很大程度在 harness 而非模型本身。Agent 编排是 harness 里再高一层的问题：多步骤/多 Agent 之间谁先谁后怎么定——固定 workflow、模型自主 ReAct 循环、或“先规划后执行”的混合，加上状态存储、失败恢复、人工接管点和评测。用过哪些开源实现如实说【真实经历】，没跑过就说读过源码/文档到什么程度，不虚报。

## Q05：Spring AI 和 MCP 框架，哪块是自带的，哪些是自己开发的？

### 面试回答

Spring AI 自带的（以 1.x 参考文档为口径，按【实际所用版本】说）：ChatClient/ChatModel 统一模型抽象与各厂商接入、prompt 模板与结构化输出、tool/function calling 的注解注册与调用循环（@Tool 声明、参数 schema 生成、结果回灌）、advisors 拦截链、RAG 组件（DocumentReader/分割器/向量库/检索 advisor）、MCP client/server boot starter（把 Spring bean 暴露为 MCP server 或聚合 MCP server 工具进 ChatClient）。自己开发的：业务 prompt 与流程设计、工具背后的真实实现与参数校验、跨调用的编排与状态管理、记忆/上下文的持久化策略、评测集与可观测埋点、鉴权与多租户。一句话边界：框架给“管道和胶水”，判断逻辑与业务正确性是自己的。

## Q07：说明 AI 项目里一个模块的流程，出现异常怎么解决、怎么识别错误？

### 面试回答

按【真实模块】套结构：流程“输入→处理→输出”逐步说，重点在异常分层识别。识别手段：全链路 traceId 串起模型调用、工具调用与落库；每步记录输入输出摘要与耗时；输出侧做结构化校验（schema/必填字段/引用是否真实存在），校验不过即判“模型输出错误”而非运行时异常；错误分类——输入异常（参数缺失、超长）、模型异常（格式漂移、幻觉、拒答）、工具异常（超时、报错）、系统异常（依赖不可用）。处理：分类重试与降级（换提示/换小模型/回退规则）、超阈值熔断、人工接管出口；bad case 沉淀进回归集，防止同类问题复发。

## Q08：AI 时代程序员有什么用，未来的发展观念？

### 面试回答

## Q11：手撕快速排序。

### 面试回答

选 pivot 把数组分成“< pivot / = pivot / > pivot”两侧递归排序。平均 O(n log n)，原地两指针版本空间 O(log n) 递归栈；最坏 O(n²) 出现在有序输入＋固定选首元素做 pivot，现场写先说明并随机化 pivot 或三数取中。代码骨架（Lomuto 分区）：

```java
void quickSort(int[] a, int l, int r) {
    if (l >= r) return;
    int pivot = a[l + (int) (Math.random() * (r - l + 1))];
    int i = l, j = r;
    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) { int t = a[i]; a[i] = a[j]; a[j] = t; i++; j--; }
    }
    quickSort(a, l, j);      // 先递归较短侧可控制栈深
    quickSort(a, i, r);
}
```

易错点：等值元素两侧都停否则死循环；`i <= j` 的交叉终止条件；全等数组的性能。详见专题卡的双指针与三路分区两个版本。
