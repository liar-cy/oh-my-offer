## Q04：怎么保证缓存和数据库之间的数据一致性？

### 面试回答

先立口径：目标是最终一致，不是强一致——缓存与数据库跨两个存储，应用层做不到两阶段原子，只能控制不一致窗口。主方案是 cache-aside 下“先提交数据库、再删除缓存”：不直接更新缓存是为了避免并发写交错产生旧值，删除让下次读重建。残余风险两类：更新库成功但删缓存失败，用订阅 binlog（canal 类 CDC）或 outbox 可靠重试驱动失效，删失败进补偿队列；删缓存后读到旧值回填的竞态，用延迟双删缩小窗口、key 版本号拒绝旧值覆盖、短 TTL 兜底。收尾给分层：TTL 是最后防线不是主机制，业务容忍度决定复杂度——商品详情秒级陈旧可接受就用轻量方案，账务类根本不该缓存放直查。

## Q05：对 CAP 原理的理解；为什么保证 CP 时可用性就会损失？

### 面试回答

CAP 指分布式数据系统三方：一致性（这里指线性一致）、可用性（每个请求都收到非错误响应）、分区容错（网络丢包延迟下系统仍工作）。前提要讲对：网络分区在分布式环境必然发生，P 不可放弃，所以真正的抉择是分区出现时在 C 和 A 里二选一。为什么选 CP 必然损失 A：分区把集群切成互不通信的两边，若两边都继续接受读写，分区愈合时同一数据出现两个分叉版本、强一致被破坏；要守住 C，就只能让其中一边拒绝写入（或读写都返回错误、等待追平），这部分请求得不到正常响应——可用性定义即被打破。ZooKeeper／etcd 是 CP 代表：选主期间整体短暂不可写；Cassandra／DNS 偏 AP：分区两侧各自可写，愈合后靠冲突策略收敛。再补两层显示深度：CAP 只在“分区时刻”做取舍，正常期还有一致性 vs 延迟的权衡（PACELC 口径）；实践中大量系统按数据项混合选择——订单余额走 CP 语义，Feed 流走 AP＋最终一致。

关联专题：[[专题题库/系统设计#SYS-031：如何理解 CAP 定理，为什么保证 CP 会损失可用性？|SYS-031：如何理解 CAP 定理？]]

## Q07：binlog 监听后数据更新到 ES，ES 的作用是什么、搜索什么内容、流量最高时直接打到 ES 吗？

原题 8—10 是同一条项目链路的连续追问；项目里“搜索什么内容”属个人事实，未记录，给可填写框架。

### 面试回答

ES 的作用：MySQL 的 B+ 树索引解决不了这个场景——多字段任意组合过滤、分词全文匹配、高亮与相关性排序、聚合统计，LIKE 加全表扫描在数据量上直接不可用；ES 用倒排索引把这些做成毫秒级，代价是它不承担事务，事实源仍是 MySQL。为什么走 binlog 同步而不是业务双写：双写把同步逻辑侵入每个写入口、失败补偿复杂，canal 类 CDC 以 binlog 为单一事实源、业务零改动，接受秒级延迟——搜索场景对“刚发布的内容多快能搜到”容忍度明确。搜索内容按真实项目填写：【商品／文档／帖子等，写清索引结构与更新频率】。流量最高时不直接裸打 ES：入口先挡一层热点查询缓存（结果 key 带查询参数与版本），ES 侧靠集群分片扩容扛量、限流与熔断保集群不被打挂、深分页用 search_after 游标改写、读写分离（写入走独立节点），大促前预热并按容量压测定水位。数字与拓扑按【真实实现】口径答。

## Q08：ES 底层的搜索数据结构了解吗，具体讲倒排索引的算法或数据结构。

### 面试回答

核心是倒排索引：正排是“文档→词”，倒排反过来，term 字典（词典树）映射到 postings list（含该词的文档 ID 列表及其词频、位置）。查询“后端 AND 面试”就是取两条 postings 求交集——词项在字典里有序，postings 内部按 doc ID 升序，交集用双指针归并，长列表配跳表指针跨块加速； postings 用 delta 编码＋位压缩（相邻 doc ID 差值小，FOR/PFZ 打包）省空间也顺带把 doc ID 有序性钉死。term 字典侧用 FST（有限状态转换机）把前缀共享的词典压进内存常驻，磁盘上按块二分加载。一次完整查询还要提：分词器建索引时处理、BM25 打分按段算再合并、段（segment）不可变、后台 merge；排序聚合不走倒排，走 doc values 列存（正排列式）。主动区分 MySQL 对比：B+ 树只适合精确与前缀匹配，任意词项组合会索引爆炸——这正是 Q07 里 ES 存在的理由。

## Q09：手撕：最大子数组乘积（LeetCode 152）。

### 面试回答

与最大子数组和的本质区别是负数：一个很小的负数乘上下一个负数可能翻身成最大，所以同时维护以当前元素结尾的最大积 `mx` 和最小积 `mn`，遍历时三者比较续接或重开。当前值为负时交换 mx 与 mn 再各自乘，是等价的省分支写法；零自动充当断点（乘后归零，下一步 max(x, 0·x) 重开）。返回历史最大。时间 O(n)、空间 O(1)。边界：非空连续子数组，单元素负数数组返回最大负数（初始化用 a[0] 而不是 0 是关键坑）；溢出按题目约束 int 范围内不处理，但口述时提一句“若可能溢出换 long”。写完用 `[-2,3,-4]`（答案 24）和 `[2,-5,-2,-1,3]` 走一遍验证。
