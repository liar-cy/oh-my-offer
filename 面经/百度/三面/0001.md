## Q01：多线程交替打印 A1B2C3，任一线程退出后其余线程不永久阻塞。

原文题号：A。

原文未给语言、线程数和退出后是否继续输出；参考解采用两个 Java 线程，任一退出则整体取消。

### 面试回答

开口先约定退出语义，再讲同步结构：

- 退出语义：本解采用任一工作线程退出就取消整个打印任务，其余线程及时结束，不要求继续补齐序列。
- 同步结构：用同一把锁保护轮次和取消状态，等待方用条件循环（while 判断条件再 wait）。
- 正常路径：打印之后修改轮次，并通知对方。
- 异常路径：异常、中断或提前返回时，在 finally 里发布取消状态并唤醒所有等待者。

这题考的就是最后一条：取消一定要在退出路径上广播出去，否则别人永久阻塞。

## Q02：LeetCode 32：最长有效括号。

原文题号：B。

### 面试回答

用栈做，栈里存的都是下标，长度靠下标相减算出来。

- 栈保存未匹配左括号的下标，并先以 −1 作为初始边界。
- 遇到左括号：下标入栈。
- 遇到右括号：先弹栈。
- 弹完为空：把当前右括号的下标作为新边界。
- 否则：用当前位置减栈顶，更新最大长度。

复杂度：时间 O(n)，空间 O(n)。

## Q03：进程、线程、协程有什么区别？

原文题号：1。

### 面试回答

一句话：三者的差别是隔离级别和调度者不同。

- 进程：资源与地址空间的隔离单位。
- 线程：进程内的执行单元。同一进程的线程共享堆等资源，各自有调用栈和执行状态。
- 协程：由语言运行时或库来管理暂停、恢复和调度，通常比内核线程更轻。

什么时候用协程：

- 适合大量网络请求这类 I/O 等待较多的并发任务，能用较少的线程承载很多等待中的工作。
- 但 CPU 密集任务要多核并行时，仍然需要多个实际执行线程或进程。

## Q04：线程切换时 CPU 需要保存哪些上下文？

原文题号：2。

### 面试回答

判断标准是：保存下来的东西要能让旧线程接着跑。

- CPU 上下文：程序计数器、栈指针、通用寄存器、标志寄存器，还有按需保存的浮点和向量寄存器。
- 内核侧：同时切换调度状态和内核栈。
- 地址空间：同一进程的线程共享，所以通常不用像跨进程切换那样换掉整套地址空间。

最后留一句余地：具体保存哪些寄存器，由 CPU 架构和操作系统实现决定。

## Q05：用户态和内核态有什么区别？

原文题号：3。

### 面试回答

先给一句定位：系统调用是用户程序请求内核服务的受控入口，比如读写文件、创建进程、操作网络。

两个级别的差别在权限：

- 用户态：权限受限，不能任意访问内核内存，也不能执行特权操作。
- 内核态：可以按硬件权限执行资源管理操作。

一次进入的过程：

- 程序通过系统调用指令进内核。
- 内核检查参数和权限，执行服务。
- 执行完返回用户态。

## Q06：从键盘输入字符到应用拿到字符，中间经历什么？

原文题号：4。

### 面试回答

以常见 Linux 桌面为例，一路是这样传上来的：

- 键盘控制器上报按键事件。
- 驱动经输入子系统把事件传递出去。
- 窗口系统或合成器按当前焦点把事件交给应用。
- 键盘布局和输入法再把按键序列转换成文字。

点题的一句：按键扫描码并不天然等于最终的 Unicode 字符，中间这几层做的就是转换。

## Q07：进程调用 malloc 后，操作系统立即分配物理内存吗？

原文题号：5。

### 面试回答

结论：不一定。

- 复用空闲块：malloc 可能直接返回分配器已有的空闲块，这些块可能早就映射了物理页。
- 只要新空间：也可能只建立虚拟映射，等首次访问时才按需分配物理页。

两个方向都别说死：

- 返回成功，不保证全部物理页立即驻留。
- 但也不能说它必然没分配物理页。

最后补一句：具体行为还受系统提交策略和内存限制影响。

## Q08：缺页中断和普通中断有什么区别？

原文题号：6。

### 面试回答

区别在“谁触发的”：

- 缺页：执行指令访问某个虚拟地址时同步触发的异常，跟这条指令访问哪里直接相关。
- 通常说的普通外部中断：来自计时器或设备，和当前指令访问哪个地址没有直接关系。

处理结果也不同：

- 内核如果能补齐映射，或者处理写时复制，就可以恢复执行。
- 处理不了就报告访问错误。

## Q09：什么是抖动，工作集模型如何缓解？

原文题号：7。

### 面试回答

先说什么是抖动：

- 活跃进程需要的页面超过了可用物理页。
- 结果就是频繁缺页、不停换入换出，大量时间花在调页上，真正有效的计算很少。

工作集模型怎么缓解：

- 用最近一段访问历史，估计进程当前正在使用的页面集合。
- 按这个集合尽量给活跃任务留够页框，不让它刚换出去又要回来。

## Q10：FIFO、LRU、Clock 页面置换算法各有什么特点？

原文题号：8。

### 面试回答

三个算法按“淘汰谁”来记：

- FIFO：淘汰最早进入的页面。简单，但不利用近期访问信息，还可能出现 Belady 异常（页框变多，缺页反而变多）。
- LRU：淘汰最久未访问的页面。符合时间局部性，但精确维护的成本高。
- Clock：按环形结构扫描引用位，给近期访问过的页面第二次机会，是低成本的近似实现。
