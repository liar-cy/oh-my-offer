# 面经知识库

整理自己及他人的面经，面向 Java 后端、AI 应用、Agent 开发及 Agent Harness 岗位。面经保留逐题口述回答，专题沉淀去重后的系统知识。

## 使用方式

在本项目的 Codex 对话中上传文字或图片，并要求整理入库即可。可附公司、岗位、轮次、作者或来源链接；缺失信息记为“未知”，作者缺失记为“匿名”。如为已收录面经的下一轮，可提供原面经编号。

不在本地保存原始上传文件。整理结果保留问题、必要上下文和来源信息；图片无法辨认的部分会明确标注。

## 目录约定

```text
面经/公司名/一面（或二面、轮次未知等）/0001.md
专题题库/Java集合.md
专题题库/Agent开发.md
AGENTS.md
.agents/skills/interview-curation/SKILL.md
```

同一公司、同一轮次可以存放多份面经。文件名在各自的“公司/轮次”目录内从 `0001.md` 开始递增，不跨目录累计。正文的 MJ 编号仍全库唯一，用来关联同一人的多轮面试，与文件名互不推导。每个专题文件连续收录多道题，每题包含“面试回答、技术细节、深挖追问”。公司、轮次和专题按实际内容创建。

答案写法统一遵循 [AGENTS.md](AGENTS.md) 第 5 节：面经的面试回答结论先行、短句列点、能当场口述；专题的技术细节按粗体小标题分组列点，做到全面且不晦涩。

## Obsidian 阅读

将本项目根目录作为 Obsidian 仓库打开，从本页进入面经或专题。目录与交叉引用使用原生标题链接，跨文件链接包含完整库内路径，避免同名 `0001.md` 混淆；无需目录插件或 HTML 锚点。更改标题或移动文件时需同步引用。
